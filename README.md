# Card Fraud Detection

This project detects fraudulent credit-card transactions from the Kaggle credit
card fraud dataset. The exploratory analysis is in English and the modeling
pipeline uses PyTorch.

It's for me a project to test my knowledge of machine learning and deep learning, and to learn more about PyTorch, since I learnt it through lectures at Trinity College Dublin.
